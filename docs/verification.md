## Обновление 1.0.3

На предоставленном пользователем CSV воспроизведена ошибка совместного доступа: File.ReadAllBytes отклонял чтение при открытом пишущем дескрипторе другой программы. FileStream с FileShare.ReadWrite смог прочитать этот же файл.

Чтение CSV и Excel переведено на снимок в памяти с совместным доступом; размер и время модификации проверяются до/после чтения. Три регрессионных теста сначала падали, затем прошли: CSV и XLSX при открытом дескрипторе записи, понятное сообщение при эксклюзивной блокировке. Исправленный FileService успешно прочитал реальный CSV: 5736 строк, 2 колонки, UTF-8, запятая, первая строка данных №1. Файл пользователя не изменялся и не включен в репозиторий.

По итогам ревью добавлена кратковременная блокировка диапазона байтов на Windows, которая предотвращает обычную параллельную запись, включая перезапись той же длины. Отдельный тест сначала воспроизвел отсутствие защиты, затем проверил запрет записи другим дескриптором во время чтения и освобождение блокировки после него. Блокировки Windows не защищают от изменения через memory-mapped views; не следует сохранять исходный файл одновременно с проверкой.

Итоговая Release-проверка: 38 Core/Infrastructure + 7 Desktop = 45 тестов, 0 ошибок и предупреждений компиляции. Повторное чтение реального CSV с блокировкой также успешно: 5736 строк и 2 колонки.
