# Проверка версии 1.0.0

Проверено 8 сентября 2026 на Windows x64, локальный SDK .NET 10.0.400.

- `scripts/build.ps1`: Release-сборка, 0 ошибок и 0 предупреждений.
- 27 тестов Core/Infrastructure: успешно.
- 7 тестов Desktop: успешно, включая реальное чтение трёх файлов, объединение источников, сохранение CSV, запрет устаревшего результата, WPF-рендеринг и адрес обновлений.
- Тесты правил сначала падали против заглушек. Два дополнительных регрессионных теста воспроизвели округление числовых SKU `123456789012` и `123456789012345` библиотечным General-форматом; исправление сохраняет полный числовой текст и прошло тесты.
- Визуально просмотрены изображения загрузки, настроек и результата из `artifacts/screenshots`.
- Независимое ревью выполнено. После исправлений повторное ревью числовых SKU, завершения проверки и упаковки не обнаружило новых замечаний.
- `scripts/package.ps1 -Version 1.0.0`: автономная win-x64 сборка, установщик и portable ZIP успешно созданы. Velopack подтвердил ранний вызов startup hook.
- Готовый self-contained `SkuMaster.exe` запущен скрыто, достиг состояния InputIdle и продолжал работать. Скрытое окно не предоставляет MainWindowHandle для CloseMainWindow; тестовый процесс завершён отдельно. Сквозной UI-сценарий проверен WPF-тестом.

Ограничения проверки:

- Установщик собран, но установка в пользовательский профиль не выполнялась.
- Нет заданного GitHub-репозитория. Проверка загрузки и установки обновления между двумя опубликованными версиями не выполнялась. Программа явно сообщает, что источник обновлений не настроен.
- Установщик не подписан коммерческим сертификатом.
- Проверены контролируемые примеры, реальные выгрузки пользователя ещё не предоставлены.
