# SKU Майстер — спецификация Windows-приложения

## Назначение

Локальное приложение для Windows 10/11 x64 с украинским интерфейсом. Пользователь загружает экспорт сайта (А, CSV), экспорт из 1С (Б, XLSX/XLS) и файл поставщика (В, XLSX/XLS), проверяет изменения и сохраняет результат через системный диалог «Зберегти як». Установка Microsoft Excel не требуется. Файлы пользователя не передаются в интернет. Рабочее название — «SKU Майстер».

## Сценарий

1. Выбрать операцию «Оновлення статусів за SKU».
2. Выбрать три файла с понятными названиями источников.
3. При необходимости изменить настройки источников, операции и экспорта.
4. Нажать «Перевірити файли». Обработка выполняется в фоне; интерфейс показывает прогресс и позволяет отменить операцию.
5. Просмотреть сводку, предупреждения и таблицу фактических изменений.
6. Нажать «Зберегти результат» и выбрать путь. Отмена диалога ничего не записывает. Повторное сохранение доступно.

Изменение файлов или настроек после проверки делает результат неактуальным и требует повторной проверки. Сохранение неактуального результата недоступно. Исходные файлы нельзя перезаписывать результатом. При ошибке записи существующий целевой файл не повреждается: запись во временный файл рядом с целевым с последующей заменой после успешного завершения.

## Правила

Доступные SKU — объединение первой колонки Б и В. Достаточно присутствия в одном источнике.

- SKU отсутствует в объединении: установить настроенный статус недоступности, по умолчанию `Временно недоступен`.
- SKU присутствует и текущий статус точно совпадает с настроенным статусом для замены (по умолчанию `Временно недоступен`): очистить status либо заменить заданным текстом, например `Новинка`.
- Другие статусы присутствующих SKU не менять.

SKU сравниваются как строки с учетом регистра; внешние пробелы при сравнении удаляются, исходное значение в результате сохраняется. Ведущие нули сохраняются для текстовых значений и явных числовых масок Excel. Нули, уже потерянные в исходном файле, не восстанавливаются догадками. Формулы в SKU источников считаются ошибкой с указанием строки, чтобы не использовать устаревшие вычисленные значения.

Строки А и их порядок сохраняются, включая повторяющиеся SKU. Пустой SKU в А остается без изменений и сопровождается предупреждением. Пустые строки источников пропускаются. Дубликаты в источниках не влияют на наличие; их количество показывается. Статистика изменений считается по строкам А, а количество уникальных SKU выводится отдельно.

## Настройки

Настройки хранятся локально в профиле пользователя, имеют версию схемы и сохраняются между запусками. Поврежденные настройки сопровождаются понятным предупреждением и заменяются значениями по умолчанию.

- Б и В: независимый переключатель «Перший рядок містить заголовки», по умолчанию выключен; выбор листа, по умолчанию первый.
- А: заголовки `sku` и `status` по умолчанию; выбор соответствующих колонок при других названиях. Дублирующиеся/отсутствующие необходимые заголовки требуют исправления выбора. Дополнительные колонки сохраняются без изменения.
- CSV: автоматическое определение разделителя (запятая, точка с запятой, табуляция) с ручным выбором; UTF-8 с BOM/без BOM и Windows-1251. При неоднозначном определении пользователь выбирает параметры, поврежденные символы молча не подставляются.
- Операция: статус для отсутствующих, статус для замены у найденных, действие «Очистити» или «Замінити», текст замены. Пустой статус для отсутствующих не допускается.
- Экспорт: CSV по умолчанию или XLSX; включение заголовков; названия выходных колонок `sku` и `status` по умолчанию. Заголовки дополнительных колонок сохраняются. Пустые и конфликтующие названия при включенных заголовках не допускаются.
- CSV-экспорт: по умолчанию кодировка и разделитель входного А; можно изменить. Ошибка представимости символов в выбранной кодировке блокирует сохранение и предлагает UTF-8. Корректное экранирование кавычек, разделителей и переводов строк.

XLSX сохраняет SKU и остальные экспортируемые значения как текст, без создания формул. CSV сохраняет точные значения, включая исходные символы; автоматические префиксы к SKU не добавляются.

## Результат проверки

- «Перевірено товарів»: число строк А с данными, включая проблемные SKU.
- «Унікальних SKU»: число непустых различных SKU после нормализации.
- «Стали недоступними»: отсутствующие SKU, чей статус фактически изменится.
- «Знову доступні»: найденные SKU, у которых правило замены фактически изменит статус. Это наличие по источникам, а не доказательство исторического изменения остатков.
- «Усього змін статусу»: сумма двух предыдущих счетчиков.
- «Без змін»: проверено минус фактически изменено.
- Предупреждения о пустых SKU и дубликатах с указанием источника и строки.

Таблица с виртуализацией: номер строки А, SKU, «Поточний статус», «Новий статус», «Причина». Фильтры: все изменения, недоступные, снова доступные. Пустой новый статус отображается как «(порожньо)», но экспортируется пустой ячейкой. Результат без изменений также можно сохранить.

## Архитектура и выбор технологий

Основной вариант: C# / .NET 10, WPF и MVVM. WPF предназначен для Windows и позволяет использовать системные диалоги без локального веб-сервера. Альтернативы: Electron удобен для веб-интерфейса, но добавляет браузерный runtime; Python/Qt подходит для обработки таблиц, но потребует отдельной организации упаковки и обновлений. Для этой Windows-only задачи выбран WPF.

- Core: модели строк, настройки операций, чистые правила сравнения, изменения и статистика; без зависимости от WPF и форматов файлов.
- Infrastructure: CSV/XLS/XLSX, локальные настройки, атомарное сохранение, обновления.
- Desktop: украинские экраны, состояние проверки, отмена, системные диалоги, виртуализированная таблица.
- Tests: проверки бизнес-правил и чтения/записи файлов на контролируемых примерах.

Операции регистрируются по стабильному идентификатору и предоставляют собственные настройки, проверку входных данных и результат преобразования. Первая версия содержит одну операцию; новые добавляются кодом в следующем выпуске без изменения файловых адаптеров и оболочки приложения. Динамическая загрузка сторонних плагинов в первую версию не входит.

## Установка и обновления

Self-contained сборка Windows x64 и установщик Velopack. Автоматическая проверка обновлений из публичного GitHub Releases при запуске, загрузка в фоне; установка после согласия пользователя на перезапуск, когда нет несохраненного результата. Ошибка сети не блокирует обработку. Есть ручная команда «Перевірити оновлення» и отображение текущей версии.

Адрес репозитория задается при сборке, секреты GitHub не включаются в приложение. Публикация через GitHub Actions по тегу версии; сборка, тесты и упаковка до выпуска. Для действующего автообновления необходим реальный репозиторий пользователя и опубликованный релиз: до их настройки показывается «Джерело оновлень не налаштовано». Подмена этой настройки фиктивным адресом недопустима. Создание репозитория и публикация релиза требуют отдельного указания пользователя. Наличие коммерческого сертификата подписи не предполагается; его подключение — отдельная настройка выпуска.

## Проверка качества

Тесты: объединение Б/В; все ветки правил; отсутствие повторного учета неизмененных статусов; настройка Новинка; заголовки источников включены/выключены; дубликаты и пустые SKU; регистр и пробелы; ведущие нули; CSV с кириллицей, кавычками, переносами строк и разными разделителями; XLS/XLSX; выходные заголовки и формат; дополнительные колонки; отмена сохранения и запрет перезаписи источников. Проверка равенства суммы измененных и неизмененных общему числу строк.

Сборка и тесты на Windows; ручной проход загрузка → проверка → просмотр → сохранение обоих форматов → повторное чтение; проверка интерфейса и длинных имен файлов. Механизм обновлений проверяется между двумя тестовыми версиями после настройки репозитория; до этого отдельно указывается, что сквозное обновление не проверено.
